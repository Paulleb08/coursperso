# Prof Perso

Professeur particulier propulsé par Claude, en une seule page web (`index.html`).

1. Ouvre `index.html` dans un navigateur et colle ta clé API Anthropic.
2. Téléverse tes cours (PDF, photos, texte) et/ou colle un export NotebookLM.
3. Le cours est restructuré en blocs : cours + 3 exercices inédits avec solutions.
4. Par bloc : « réexplique plus simplement », « nouveaux exercices ».
5. Par exercice : 📷 envoie la photo de ta copie → correction détaillée + note.

NotebookLM n'a pas d'API publique : exporte/copie tes notes ou ton guide d'étude et colle-les.
Tout est stocké en local dans le navigateur (localStorage).
